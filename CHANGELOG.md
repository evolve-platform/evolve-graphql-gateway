and is generated by [Changie](https://github.com/miniscruff/changie).


## v1.0.0 - 2026-09-29
### Added
* Compress responses to clients (gzip, br, zstd, deflate, negotiated via Accept-Encoding, responses of 1KiB and up) and accept compressed request bodies, so a compressing reverse proxy is no longer needed. Tune or disable via traffic_shaping.router.compression in your own config.
### Changed
* Upgrade Hive Router from v0.0.81 to v0.3.0. Input-object and @oneOf variables are now validated before execution, so malformed variables that subgraphs used to accept are rejected. LOG_FORMAT only accepts text or json (pretty-tree/pretty-compact were removed), the trace log level is gone from release builds, and demand-control metrics are prefixed with hive.router.demand_control.

## v0.2.0 - 2026-08-25
### Added
* Report usage to Hive Console. Set HIVE_USAGE_REPORTING_ENABLED=true plus HIVE_ACCESS_TOKEN (a registry token with write permission — not HIVE_CDN_KEY), and HIVE_TARGET for a current hvo1/hvu1/hvp1 token. Tune with HIVE_USAGE_REPORTING_SAMPLING_RATE, HIVE_USAGE_REPORTING_EXCLUDE_EXPRESSION (VRL) and HIVE_USAGE_REPORTING_ENDPOINT.

## v0.1.1 - 2026-08-22
### Fixed
* Publish the image again: v0.1.0 was tagged but never pushed to GHCR, because a CI bug failed its arm64 release build. There is no ghcr.io/evolve-platform/evolve-gateway:0.1.0, :0.1 or :latest — pin 0.1.1 or newer.

## v0.1.0 - 2026-08-22
### Added
* Subgraph URLs can be rewritten per request with SUBGRAPH_URL_EXPRESSION, a VRL expression over the URL from the supergraph. Unset, nothing is rewritten; the README shows the blue/green recipe for Azure Container Apps.

## v0.0.2 - 2026-08-19
### Fixed
* Configure OLTP_HEADERS via official route

## v0.0.1 - 2026-08-19
### Fixed
* Default trace context propagation to W3C `traceparent` and make B3 opt-in. With B3-only defaults the gateway dropped the incoming context and started a new trace, so storefront, gateway and subgraph spans landed in three separate single-service traces.
